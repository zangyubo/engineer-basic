杂化轨道理论 · 教程（sp / sp² / sp³）

本节按"为什么 → 数学描述 → 形状 → 判断方法 → 典型例子"的顺序讲解杂化轨道理论。3D 模型由角度函数 h_i(u)=c_s+√3·c_p·(d_i·u) 直接生成：单位球面采样方向 u，半径 r = r₀|h(u)|^q（q=2.5，角度分布集中、瓣细长），再沿轨道方向拉伸；红色 = 正相位（大瓣）、蓝色 = 负相位（小瓣），可拖拽旋转。

01为什么需要杂化轨道？—— CH₄ 之谜

C 的价电子构型为 2s²2p²，基态只有 2 个未成对电子，按理只能形成 2 个共价键；但 CH₄ 却存在 4 个完全等价的 C–H 键（键长、键能相同，键角均为 109°28′），用"基态原子轨道直接成键"无法解释。

杂化轨道理论（Pauling 提出）：原子成键时，中心原子将 能量相近的原子轨道（如 2s 与 2p）先进行线性组合（数目不变），得到一组能量相等、方向性更强的新轨道——杂化轨道。s 与 p 叠加使杂化轨道"一头大一头小"，大瓣朝键方向集中，与配体原子轨道重叠更多、成键能力更强。

基本规则：杂化轨道数 = 参与杂化的原子轨道数 = σ 键数 + 孤对电子对数。π 键由未杂化的 p 轨道形成，不计入。

02数学描述：角度函数与实心曲面

令方向单位向量 u=(sinθcosφ, sinθsinφ, cosθ)。指向 d_i 的杂化轨道角度函数为 h_i(u) = c_s + √3·c_p·(d_i·u)，其中 c_s²+c_p²=1，d_i·u = cosγ 为该方向与轨道方向的夹角余弦。等性杂化系数如下。

绘制：在球坐标网格上采样方向 u，取半径 r = r₀·(|h_i(u)|/h_max)^q（q=2.5，角度分布集中、瓣细长），再沿轨道方向 d_i 拉伸 1.6 倍，顶点 P = r·u 组成实心曲面；h>0 区域为红色大瓣、h<0 区域为蓝色小瓣。节面处 h=0 → r≈0，两瓣在原子核处相接。

03三种等性杂化的形状
单个 sp³ 杂化轨道：大瓣（红）+ 小瓣（蓝）

单个杂化轨道（d=(1,1,1)/√3）：键方向 h>0 形成大红瓣，反方向 h<0 形成小蓝瓣。节面 h=0 处 cosγ=−1/3，即与轨道方向夹角 109.47° 的圆锥面，分隔大瓣与小瓣。

sp：两个杂化轨道 · 180° 直线

sp 杂化：d₁=(0,0,1)、d₂=(0,0,−1)，两轨道沿同轴反向，正瓣朝外、负瓣朝内，键角 180°（如 CO₂、C₂H₂）。c_s=c_p=1/√2。

sp²：三个杂化轨道 · 120° 平面三角

sp² 杂化：d_k=(cos 2πk/3, sin 2πk/3, 0)，k=0,1,2，三轨道位于 xy 平面互成 120°（如 BF₃、C₂H₄），正瓣指向三角顶点。c_s=1/√3、c_p=√(2/3)。

sp³：四个杂化轨道 · 109°28′ 正四面体

sp³ 杂化：d=(±1,±1,±1)/√3 四方向指向正四面体顶点，键角 109°28′（如 CH₄），大红瓣朝外、小蓝瓣朝中心。c_s=1/2、c_p=√3/2。

04杂化类型的判断（考试核心方法）
  • 第一步：数中心原子的 σ 键数（单键算 1；双键、三键中只算 1 个 σ）与 孤对电子对数。
  • 第二步：n = σ 键数 + 孤对电子对数；n=2 → sp，n=3 → sp²，n=4 → sp³。
  • 第三步：结合 VSEPR 定构型——无孤对时：sp 直线、sp² 平面三角、sp³ 正四面体；有孤对时键角压缩（见 06）。
  • 例：CO₂（C 有 2 个 σ、0 孤对 → n=2 → sp）；BF₃（3 个 σ → n=3 → sp²）；CH₄（4 个 σ → n=4 → sp³）。

06不等性杂化与键角
  • s 成分与键角的关系：s 成分 = c_s² = −cosθ/(1−cosθ)。键角越小，s 成分越大。
  • NH₃：sp³ 不等性杂化，孤对电子占据的轨道 s 成分增大（约 0.23），成键轨道 s 成分减小，键角被压缩至 ≈107°（三角锥）。
  • H₂O：sp³ 不等性杂化，两对孤对电子使 s 成分更大（约 0.20），键角压缩至 ≈104.5°（V 形）。
  • 原因：孤对电子只受一个原子核吸引、电子云更"胖"，对成键电子对排斥更大，挤压键角。
07考点小结
  • 杂化轨道数 = σ 键数 + 孤对电子对数 → n=2/3/4 对应 sp / sp² / sp³。
  • 等性杂化键角：sp 180°、sp² 120°、sp³ 109°28′。
  • 孤对电子压缩键角（不等性杂化）：NH₃ ≈107°、H₂O ≈104.5°。
  • π 键由未杂化 p 轨道形成：sp² 余 1 个 p、sp 余 2 个 p。
  • 杂化轨道"一头大一头小"，大瓣朝键方向，成键能力比纯 s / 纯 p 更强。
