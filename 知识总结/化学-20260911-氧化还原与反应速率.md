## 一、氧化还原与电化学（考点 3.3）

### 1. 基本概念（3.3.1）

- **氧化数（化合价）**：单质为 0；化合物中 H 为 +1、O 为 −2；离子等于所带电荷
- **氧化还原反应的本质**：电子转移（得失）；特征：氧化数变化
- **氧化剂**：得电子、氧化数降低、被还原（产物为还原产物）
- **还原剂**：失电子、氧化数升高、被氧化（产物为氧化产物）
- **氧化还原电对**：氧化型/还原型，如 Fe³⁺/Fe²⁺、Cu²⁺/Cu

### 2. 方程式配平（3.3.2）

**氧化数法**步骤：
1. 标出各元素氧化数，找出氧化数升、降的元素
2. 求升价与降价的最小公倍数，确定氧化剂/还原剂系数
3. 配平非氧化还原部分（用观察法补 H⁺、OH⁻、H₂O）

**离子-电子法**（半反应法，考试推荐）：将反应拆成氧化半反应 + 还原半反应，分别配平原子数与电荷数，再按电子守恒合并。
- **酸性介质**：用 H⁺ 和 H₂O 配平（含氧多的一边加 H⁺，另一边加 H₂O），如 MnO₄⁻ + 5e⁻ + 8H⁺ → Mn²⁺ + 4H₂O
- **碱性介质**：用 OH⁻ 和 H₂O 配平（含氧多的一边加 H₂O，另一边加 2 倍 OH⁻）
- 配平后核对两边原子总数与电荷总数均相等

### 3. 原电池（3.3.3）

- 组成：两个半电池（电极 + 电解质溶液）+ **盐桥**（沟通内电路、平衡电荷）
- **负极**：发生氧化（电子流出）；**正极**：发生还原（电子流入）；电子经外电路由负极流向正极
- 电池符号：(−) Zn | Zn²⁺ || Cu²⁺ | Cu (+)
- **电动势 E = φ(正极) − φ(负极)**

### 4. 电极电位（3.3.4–3.3.6）

- **标准电极电位 φ⁰**：以标准氢电极（H⁺/H₂，φ⁰ = 0）为基准测得；φ⁰ 与反应方向、化学计量数无关
- φ⁰ 越大 → 氧化型的**氧化性越强**（对应还原型还原性越弱）
- **能斯特方程**（25℃）：**φ = φ⁰ + (0.0592/n)·lg([氧化型]/[还原型])**
- 使用注意：
  - 气体以**相对分压** p/p⁰ 代入；难溶固体、纯液体**不列入**式
  - 电极反应中出现的 H⁺、OH⁻ 或沉淀相关离子（如 Cl⁻）要**计入**（写在哪一边按哪一边处理）
- 应用：
  - 判断反应方向：**E = φ⁰(氧化剂) − φ⁰(还原剂) > 0 正向自发**（强氧化剂 + 强还原剂 → 弱还原剂 + 弱氧化剂）
  - 比较氧化性/还原性强弱：φ⁰ 越大氧化型氧化性越强（如 MnO₄⁻ > Cr₂O₇²⁻ > Fe³⁺ > Sn⁴⁺）
  - 浓度影响：增大氧化型浓度 → φ 增大（**实验室用浓盐酸与 MnO₂ 制 Cl₂** 的原理）
  - 计算平衡常数：**lgK = nE⁰/0.0592**（25℃）

### 5. 电解（3.3.7）

- 电解池：**阳极接电源正极（氧化）、阴极接负极（还原）**
- 阳极放电顺序（惰性电极）：活性电极自身溶解 > S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根
- 阴极放电顺序（阳离子）：Ag⁺ > Cu²⁺ > H⁺ > Fe²⁺ > Zn²⁺（金属越不活泼越易得电子）
- **法拉第定律**：析出物质质量 m = (M·I·t)/(n·F)（F ≈ 96500 C/mol）

### 6. 金属腐蚀与防护（3.3.8）

- **电化学腐蚀**（主要）：吸氧腐蚀（中性/弱酸性，Fe 为负极被氧化、O₂ 在正极得电子）
- 防护方法：牺牲阳极阴极保护（接更活泼金属）、外加电流阴极保护、表面涂层

## 二、化学反应速率与化学平衡（考点 3.4）

### 1. 化学反应速率（3.4.1）

- 定义：v = |Δc|/Δt，单位 mol/(L·s)
- **影响速率的因素**：
  - 浓度：增大浓度速率加快
  - 温度：升高温度速率加快（**阿伦尼乌斯方程 k = A·e^(−Ea/RT)**，lnk 与 1/T 线性）
  - 催化剂：降低活化能 Ea，同等加快正逆反应
  - 接触面积、压强（对气体）
- **速率方程**：v = k·c(A)^x·c(B)^y，**x、y 由实验测定**，不等于化学计量数

### 2. 化学热力学简介（3.4.2）

- 焓变 ΔH：**吸热为正（ΔH > 0）、放热为负（ΔH < 0）**；恒压反应热 **ΔH = Qp**
- 熵变 ΔS：混乱度变化
- **吉布斯自由能 ΔG = ΔH − T·ΔS；ΔG < 0 反应自发**；与平衡常数 **ΔG⁰ = −RT·lnK**
- **热化学方程式**写法（常考）：标明**物质的聚集状态**（g/l/s/aq）、注明 298K/100kPa 标准条件；ΔH 与化学计量数成正比（系数×2，ΔH×2）
- **盖斯定律**：反应热只与始态、终态有关，与途径无关——**总反应 ΔH = 各分步反应 ΔH 之和**（可由此计算难以直接测定的反应热）

### 3. 气体分压定律（3.4.2 混合气体，常考计算）

- **p总 = pA + pB + pC + …**（各组分分压之和）
- 某组分分压 = 摩尔分数 × 总压：**pᵢ = xᵢ·p**
- **注意：必须用摩尔分数（体积分数 = 摩尔分数）计算，不能用质量分数**
- 例：含 1%（质量比）H₂S 的丁烷混合气，p总 = 101kPa → 需先换算 n(H₂S) 与 n(C₄H₁₀) 求摩尔分数，再算分压

### 3. 化学平衡（3.4.3）

- 平衡常数：aA + bB ⇌ cC + dD，**K = [C]ᶜ[D]ᵈ / [A]ᵃ[B]ᵇ**
- **K 只随温度变化**，不随浓度、压强变化；K 越大反应进行越完全
- **勒夏特列原理**：改变条件（浓度、压强、温度），平衡向**减弱该改变**的方向移动
  - 增大反应物浓度 → 正向移动
  - 增大压强（气体）→ 向气体分子数减少方向移动；等分子数反应不受影响
  - 升高温度 → 向吸热方向移动
  - 催化剂不移动平衡，只改变到达平衡的时间
- 转化率、Q 与 K 比较（Q < K 正向、Q > K 逆向）

## 三、例题（一个知识点配一个题）

1. **氧化数**：KMnO₄ 中 Mn 的氧化数？
   **答**：+1 + x + 4×(−2) = 0 → x = **+7**。
2. **配平**：KMnO₄ + HCl → MnCl₂ + Cl₂ + KCl + H₂O
   **答**：2KMnO₄ + 16HCl = 2MnCl₂ + 5Cl₂ + 2KCl + 8H₂O（Mn +7→+2 降 5；Cl −1→0 升 1×2；5 与 2 的最小公倍数为 10）。
3. **原电池**：Zn–Cu 原电池中，哪个极是负极？电子流向？
   **答**：Zn 为负极（Zn − 2e⁻ → Zn²⁺）；电子经外电路由 Zn 极流向 Cu 极。
4. **能斯特方程**：25℃ 下 φ⁰(Cu²⁺/Cu)=0.34V，若 c(Cu²⁺)=0.01 mol/L，φ(Cu²⁺/Cu)？
   **答**：φ = 0.34 + (0.0592/2)·lg(0.01) = 0.34 − 0.0592 = **0.281V**。
5. **反应方向判断**：φ⁰(Fe³⁺/Fe²⁺)=0.77V，φ⁰(I₂/I⁻)=0.54V，Fe³⁺ 能否氧化 I⁻？
   **答**：E = 0.77 − 0.54 = 0.23V > 0 → 能，2Fe³⁺ + 2I⁻ = 2Fe²⁺ + I₂。
6. **电解**：电解 CuCl₂ 溶液（惰性电极），阴、阳极产物？
   **答**：阴极 Cu²⁺ 得电子析出 Cu；阳极 Cl⁻ 失电子放出 Cl₂。
7. **速率影响因素**：升高温度，反应速率增大的本质原因？
   **答**：分子动能增大、有效碰撞比例增大（活化分子百分数增大），速率常数 k 增大（阿伦尼乌斯）。
8. **平衡移动**：N₂ + 3H₂ ⇌ 2NH₃（放热），增大压强平衡如何移动？升高温度呢？
   **答**：增大压强 → 向气体分子数少的方向（正反应）移动；升高温度 → 向吸热方向（逆反应）移动。
9. **盖斯定律**：Sn(s)+Cl₂(g)→SnCl₂(s) ΔH=−349.8kJ；SnCl₂(s)+Cl₂(g)→SnCl₄(l) ΔH=−195.4kJ，求 Sn(s)+2Cl₂(g)→SnCl₄(l) 的 ΔH？
   **答**：两式相加：ΔH = −349.8 + (−195.4) = **−545.2 kJ**。
10. **分压定律**：某混合气体 p总=101.325kPa，O₂ 的摩尔分数为 0.21，O₂ 分压？
    **答**：p(O₂) = 0.21 × 101.325 ≈ **21.3 kPa**（体积分数=摩尔分数）。
11. **lgK 计算**：2Fe³⁺+Cu = 2Fe²⁺+Cu²⁺，φ⁰(Fe³⁺/Fe²⁺)=0.77V、φ⁰(Cu²⁺/Cu)=0.34V，求 25℃ 平衡常数 K？
    **答**：E⁰ = 0.77−0.34 = 0.43V，n=2 → lgK = 2×0.43/0.0592 ≈ 14.5 → **K ≈ 3×10¹⁴**。

## 四、本日小结

- 氧化还原核心：氧化数法配平 + 电极电位判断反应方向（φ⁰大者氧化型氧化性强）；离子-电子法配平（酸 H⁺/碱 OH⁻）
- 电化学核心：原电池负极氧化、电解池阳极氧化；能斯特方程浓度项；lgK = nE⁰/0.0592
- 热化学核心：ΔH 符号、标聚集状态、盖斯定律；分压定律必须用摩尔分数
- 速率平衡核心：勒夏特列原理三条件（浓度/压强/温度）+ K 只随温度变
