01原子结构（考点 3.1.1 / 3.1.2）
原子的组成

原子 = 原子核（质子 Z + 中子 N）+ 核外电子。

质量数 A = Z + N；元素符号：左上角质量数、左下角质子数，如 ¹⁶O、²³⁵U。

  • 每层最多容纳 2n² 个电子；s 亚层 2、p 亚层 6、d 亚层 10、f 亚层 14
  • 能量最低原理：电子优先填入能量最低的轨道（4s 能量低于 3d，先填 4s 后填 3d）
  • 泡利不相容原理：同一轨道最多 2 个电子，且自旋方向相反
  • 洪特规则：等价轨道优先分占、自旋平行；半满/全满结构稳定 → 特例：Cr 3d⁵4s¹、Cu 3d¹⁰4s¹
电子云与原子轨道

电子云 = 电子出现概率的空间分布；原子轨道 = 波函数描述的空间区域。

  • s 轨道：球形，1 个取向；p 轨道：哑铃形（两个沿轴瓣），3 个取向（px、py、pz）；d 轨道：花瓣形，5 个取向
  • 每层轨道总数 = n²；每亚层轨道数 = 2l+1

元素周期律

周期表：7 个周期、18 列（16 个族）；周期数 = 电子层数，主族族数 = 最外层电子数。

原子半径递变规律（核心考点）：

  • 同周期从左 → 右 减小（核电荷增大，对电子引力增强）
  • 同族从上 → 下 增大（电子层数增加，屏蔽作用增大）
  • 电离能：同周期增大、同族减小；第一电离能特例：Be（2s² 全满）> B（2p¹）
  • 电负性：F 最大（4.0）；同周期增大、同族减小
  • 金属性：同周期减弱、同族增强；非金属性相反

化学键、分子结构与晶体（考点 3.1.3）
  • 离子键：阴、阳离子间静电作用（NaCl）；无饱和性、无方向性；强弱看离子势 z/r（电荷↑半径↓ → 键增强：KCl < CaCl₂ < ScCl₃）
  • 共价键：有饱和性、方向性；σ 键（头碰头）+ π 键（肩并肩）；单键 = 1σ，双键 = 1σ+1π，三键 = 1σ+2π；配位键（电子对一方提供，如 NH₄⁺、[Ag(NH₃)₂]⁺）
  • 杂化轨道：杂化轨道数 = σ 键数 + 孤对电子对数
杂化类型杂化轨道数键角空间构型典型分子

sp²3120°平面三角BF₃、C₂H₄

  • 不等性杂化：孤对电子压缩键角 → NH₃ ≈107°（三角锥，PCl₃ 同）、H₂O ≈104.5°（V 形，H₂S、SO₂ 同）；配离子 [Ag(NH₃)₂]⁺ 为 sp 直线形
  • 键的极性与分子极性（常考判断）：极性键 = 不同元素成键（电负性差越大极性越大）；多原子分子看构型对称性——CO₂（直线）非极性、SO₂（V 形）极性；CH₄ 非极性、NH₃/H₂O 极性
  • 分子间力：取向力（极性-极性）、诱导力（极性-非极性）、色散力（一切分子，分子越大越强）；氢键 X–H···Y（X、Y=N/O/F）：HF、H₂O、NH₃、H₃BO₃、CH₃OH、H₃PO₄ 有；HCl、H₂S、PH₃ 无（半径大）
  • 晶体类型（熔沸点/硬度）：原子晶体（金刚石、SiC、SiO₂）最高 > 离子晶体（NaCl）较高 > 金属晶体（良导体、延展）> 分子晶体（CO₂、I₂）最低

02溶液（考点 3.2）
稀溶液的依数性（3.2.1）
依数性规律公式
蒸气压下降溶质使溶剂蒸气压降低Δp = p⁰·x_B（拉乌尔定律）
沸点升高与溶质粒子数成正比ΔT_b = K_b·m
凝固点降低与溶质粒子数成正比ΔT_f = K_f·m
渗透压与溶质浓度、温度成正比π = cRT（范特霍夫方程）
要点：依数性只取决于 溶质粒子总数。电解质乘电离粒子数 i（NaCl i=2、CaCl₂ i=3）；质量摩尔浓度 m = 溶质物质的量 / 溶剂质量(kg)
酸碱电离平衡（3.2.2）

一元弱酸：HA ⇌ H⁺ + A⁻，Ka = [H⁺][A⁻]/[HA]；pH = −lg[H⁺]

近似计算（c/Ka ≥ 500）：[H⁺] ≈ √(Ka·c)；电离度 α 随稀释增大

缓冲溶液（弱酸 + 共轭碱）：pH = pKa + lg([盐]/[酸])；等浓度时 pH = pKa

水的离子积：Kw = [H⁺][OH⁻] = 1.0×10⁻¹⁴（25℃）；pH + pOH = 14

酸碱质子理论：酸 = 质子供体、碱 = 质子受体（共轭酸碱对：HAc/Ac⁻、NH₄⁺/NH₃）；盐类水解：强碱弱酸盐水解显碱性（NaAc）、强酸弱碱盐显酸性（NH₄Cl），"越弱越水解"

多相离子平衡 / 溶度积（3.2.3）

难溶电解质：A_mB_n(s) ⇌ mAⁿ⁺ + nBᵐ⁻，Ksp = [Aⁿ⁺]ᵐ·[Bᵐ⁻]ⁿ

  • 同离子效应：加入相同离子使溶解度减小（如 CaSO₄ 中加 CaCl₂）
  • Ksp 与溶解度比较：同类型可直接比 Ksp；不同类型（如 AgCl 与 Ag₂CrO₄）须先算溶解度再比
  • 沉淀判断：Q > Ksp 生成沉淀；Q < Ksp 沉淀溶解；Q = Ksp 恰好饱和
  • 分步沉淀：多种离子共存时，Q 先达到 Ksp 者先沉淀
03例题（一个知识点配一个题，点击题目看答案）
1基态 Cr 的价电子排布为？
答：3d⁵4s¹（洪特规则半满稳定，不是 3d⁴4s²）。
2Na、Mg、Al、Cl 原子半径由大到小？
答：Na > Mg > Al > Cl（同周期第三周期，从左到右减小）。
3BF₃ 中 B 的杂化类型与分子构型？
答：B 有 3 个 σ 键、0 孤对 → sp² 杂化，平面三角形，键角 120°。
4质量摩尔浓度均为 0.1 mol/kg 的葡萄糖与 NaCl 溶液，哪个凝固点更低？
答：NaCl（i=2，粒子数是葡萄糖 2 倍，ΔT_f 更大，凝固点更低）。
50.1 mol/L HAc 与 0.1 mol/L NaAc 等体积混合（pKa=4.74），pH？
答：pH = pKa + lg(0.1/0.1) = 4.74。
6某溶液 c(Ag⁺)·c(Cl⁻)=2×10⁻¹⁰，Ksp(AgCl)=1.8×10⁻¹⁰，是否生成沉淀？
答：Q = 2×10⁻¹⁰ > Ksp = 1.8×10⁻¹⁰ → 生成 AgCl 沉淀。
7CO₂ 与 SO₂ 谁是极性分子？为什么？
答：SO₂ 极性（V 形，键极性不抵消）；CO₂ 非极性（直线形，两 C=O 极性抵消）。
8HCl、H₂S、NH₃、H₃BO₃、PH₃ 中哪些能形成氢键？
答：NH₃、H₃BO₃（含 N–H、O–H，N/O 原子半径小）；HCl、H₂S、PH₃ 中 Cl/S/P 半径大，不能。
9AgCl（Ksp=1.8×10⁻¹⁰）与 Ag₂CrO₄（Ksp=1.1×10⁻¹²）谁的溶解度大？能否直接看 Ksp？
答：不能直接比（不同类型）。AgCl：s=√Ksp≈1.3×10⁻⁵；Ag₂CrO₄：s=∛(Ksp/4)≈6.5×10⁻⁵ mol/L → 实际 Ag₂CrO₄ 溶解度更大。
10金刚石、NaCl、Fe、CO₂ 熔点由高到低？
答：金刚石（原子晶体）> NaCl（离子晶体）> Fe（金属晶体）> CO₂（分子晶体）。
