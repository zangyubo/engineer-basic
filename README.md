# 注册电气工程师基础考试复习

本仓库用于记录 **注册电气工程师基础考试** 的复习笔记、刷题与进度管理。

## 项目说明

注册电气工程师考试分为 **基础考试** 和 **专业考试** 两个阶段，基础考试全部为客观题（单选），通过后方可报考专业考试。基础考试分为上、下午两个半场：

| 场次 | 科目方向 | 主要内容 |
|------|----------|----------|
| 上午 | 公共基础 | 高等数学、普通物理、普通化学、理论力学、材料力学、流体力学、计算机应用基础、电工电子技术、工程经济、法律法规 |
| 下午 | 专业基础 | 电路、电磁场、电机学、模拟电子技术、数字电子技术、电气工程基础（电力系统分析、发电厂电气部分、高电压技术等） |

## 使用说明

- 复习笔记、参考资料统一放入 `docs/` 目录，该目录已被 `.gitignore` 忽略，不会纳入版本控制；
- 其他内容（如错题整理、刷题记录、进度打卡等）可按需在仓库根目录新增目录。
